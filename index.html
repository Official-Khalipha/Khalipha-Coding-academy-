HTML COURSE • LESSON 1

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create the structure of web pages.

What is HTML?

HTML is used to tell the browser what should appear on a webpage, such as headings, paragraphs, images, links and buttons.

Simple HTML Example

<h1>Welcome to Khalipha Coding</h1> <p>Learn Web Development in Hausa.</p>

Common HTML Elements

  • <h1> — Heading
  • <p> — Paragraph
  • <a> — Link
  • <img> — Image
  • <button> — Button

Lesson Summary

HTML builds the structure of a webpage. CSS is used to style that structure, while JavaScript adds interaction and functionality.

HTML COURSE • LESSON 2

HTML Structure

Every HTML document has a basic structure that tells the browser how the webpage is organized.

Basic HTML Structure

<!DOCTYPE html> <html> <head> <title>My Website</title> </head> <body> <h1>Hello World</h1> </body> </html>

Main Parts

  • <!DOCTYPE html> — yana sanar da browser cewa HTML5 ake amfani da shi.
  • <html> — shi ne babban container na page.
  • <head> — yana ɗauke da bayanan page.
  • <title> — sunan da yake bayyana a browser tab.
  • <body> — duk abin da user yake gani a page.

HTML COURSE • LESSON 3

HTML Elements

HTML elements su ne abubuwan da ake amfani da su wajen gina structure na webpage.

Common HTML Elements

  • <h1> — babban heading.
  • <h2> — heading na biyu.
  • <p> — paragraph.
  • <a> — link.
  • <img> — image.
  • <button> — button.
  • <ul> — unordered list.
  • <li> — list item.

Example

<h1>Khalipha Coding Academy</h1> <p>Learn Web Development in Hausa.</p> <button>Start Learning</button>

Lesson Summary

HTML elements suna taimaka mana wajen tsara abubuwan da za su bayyana a webpage.

HTML COURSE • LESSON 4

HTML Attributes

HTML attributes suna ƙara ƙarin bayani ko umarni ga HTML element.

Example

<a href="https://example.com"> Visit Website </a>

A nan href attribute ne. Yana gaya wa browser inda link ɗin zai kai user.

Common HTML Attributes

  • href — adireshin link.
  • src — inda image ko file yake.
  • alt — bayanin image.
  • id — unique identification na element.
  • class — grouping/style na elements.
  • title — ƙarin bayani game da element.

Image Attribute Example

<img src="logo.png" alt="Khalipha Coding Logo">

A wannan misalin, src yana nuna inda hoton yake, yayin da alt yake bayyana abin da hoton yake wakilta.

Lesson Summary

Attributes suna ba HTML elements ƙarin bayani ko wasu ayyuka.

HTML COURSE • LESSON 5

HTML Links

HTML links suna ba mu damar haɗa webpage ɗaya da wani webpage, website, ko wani wuri a cikin page.

Basic Link

<a href="https://example.com"> Visit Website </a>

<a> ana amfani da shi wajen ƙirƙirar link, yayin da href yake nuna inda link ɗin zai kai.

Open Link in New Tab

<a href="https://example.com" target="_blank"> Open Website </a>

target="_blank" yana sa link ya buɗe a sabon tab.

Internal Link

<a href="#about"> About Us </a>

Wannan yana iya kai user zuwa wani section da yake da id="about".

Abubuwan da za ka tuna

  • <a> — yana ƙirƙirar link.
  • href — yana nuna inda link zai kai.
  • target="_blank" — yana buɗe link a sabon tab.
  • Za ka iya amfani da link wajen haɗa sections ko pages.

Lesson Summary

HTML links suna taimaka mana wajen haɗa shafuka da wurare daban-daban na website.

CSS COURSE • LESSON 1

Introduction to CSS

CSS stands for Cascading Style Sheets. Ana amfani da CSS wajen tsara da kawata HTML webpage.

What is CSS?

CSS yana sarrafa abubuwa kamar launi, girman rubutu, spacing, layout da responsive design.

Simple Example

h1 {color: green;font-size: 30px;}

CSS Syntax

selector {property: value;}
  • selector — element ɗin da ake son gyarawa.
  • property — abin da ake son canzawa.
  • value — ƙimar da za a ba property.

CSS COURSE • LESSON 2

CSS Selectors

CSS selectors suna gaya wa browser wane HTML element ake son a yi wa styling.

Element Selector

p {color: blue;}

Class Selector

.card {  padding: 20px;}

ID Selector

#header {background: green;}

Universal Selector

* {margin: 0;padding: 0;}

Za ka iya amfani da selectors daban-daban gwargwadon element ɗin da kake son gyarawa.

CSS COURSE • LESSON 3

Colors, Fonts & Text

CSS yana ba mu damar sarrafa yadda rubutu yake bayyana a webpage.

Text Color

p {color: #0d2e1a;}

Font Size

p {font-size: 18px;}

Font Weight

h2 {font-weight: bold;}

Text Alignment

h1 {text-align: center;}

Background Color

body {background-color: #fdfcf5;}

CSS COURSE • LESSON 4

CSS Box Model

Duk HTML element ana iya kallonsa kamar akwatin da yake da content, padding, border da margin.

Box Model

.box {width: 300px;padding: 20px;border: 2px solid black;margin: 20px;}

Content

Content shi ne ainihin abin da yake cikin element.

Padding

Padding shi ne sararin da yake tsakanin content da border.

Border

Border shi ne layin da yake kewaye da element.

Margin

Margin shi ne sararin da yake wajen border.

CSS COURSE • LESSON 5

CSS Flexbox

Flexbox hanya ce ta CSS da ake amfani da ita wajen tsara da jera elements cikin sauƙi.

Enable Flexbox

.container {display: flex;}

Justify Content

.container {display: flex;justify-content: center;}

Align Items

.container {display: flex; align-items: center;}

Gap

.container {display: flex;gap: 20px;}

Flexbox yana da amfani sosai wajen yin navigation, cards, buttons da responsive layouts.

JAVASCRIPT COURSE

Learn JavaScript

Learn the fundamentals of JavaScript and make websites interactive.

Lesson 1: Introduction to JavaScript

JavaScript is a programming language used to make websites interactive and dynamic.

What is JavaScript?

JavaScript allows a website to respond to user actions such as clicking buttons, submitting forms and changing content.

Lesson 2: Variables and Data Types

Learn how JavaScript stores and works with different types of data.

Variables

Variables are used to store information. JavaScript commonly uses let, const and var.

Example:

let name = "Usman";const age = 20;

Data Types

Common data types include String, Number, Boolean, Array and Object.

Lesson 3: Functions

Learn how to create reusable blocks of JavaScript code.

What is a Function?

A function is a block of code designed to perform a particular task.

function greet() {alert("Hello!");}greet();

Lesson 4: Events

Learn how JavaScript responds to actions performed by users.

JavaScript Events

Events happen when users interact with a webpage, such as clicking a button.

button.addEventListener("click", function() {alert("Button clicked!"); });

Lesson 5: DOM Manipulation

Learn how JavaScript can access and change HTML elements.

What is the DOM?

The DOM allows JavaScript to access HTML elements and change their content, style or attributes.

document.getElementById("title").textContent = "Hello JavaScript";
